#ГруппаЧисел

💡 Подсказки

В греческом числа 3 и 4 имеют разные формы по родам (τρία / τρεις, τέσσερα / τέσσερις). Составные числа образуются сложением: είκοσι ένα = 21. Порядковые числительные согласуются с существительным по роду.

📘 Правила и примеры употребления

1) После числительных обычно используется существительное во множественном числе: τρία βιβλία (три книги), πέντε άνθρωποι (пять человек).

2) Числительные 1, 3, 4 согласуются по роду с существительным, а большинство остальных форм обычно не меняется: ένας φίλος, μία φίλη, ένα παιδί.

3) В сложных числах сначала идут десятки, потом единицы: είκοσι δύο (22), τριάντα ένα (31), σαράντα τέσσερα (44).

Склонение количественных числительных

В современном греческом склоняются только 1,3,4 и сотни.

Склонение цифр (1,3,4)

Тип Муж. род Жен. род Сред. род Пример
1 (один) ένας μία / μια ένα ένας μαθητής / μία μαθήτρια / ένα παιδί
3 (три) τρεις τρεις τρία τρεις φίλοι / τρία σπίτια
4 (четыре) τέσσερις τέσσερις τέσσερα τέσσερις μέρες / τέσσερα βιβλία

Склонение сотен (200–900)

Сотни в греческом обычно согласуются по роду с существительным. Часто встречаются формы для муж./жен. и отдельные формы для среднего рода: διακόσιοι / διακόσιες / διακόσια, τριακόσιοι / τριακόσιες / τριακόσια и т.д.

Значение Муж. род Жен. род Сред. род Пример
200 διακόσιοι διακόσιες διακόσια διακόσιοι μαθητές / διακόσιες σελίδες / διακόσια ευρώ
300 τριακόσιοι τριακόσιες τριακόσια τριακόσιοι άνθρωποι / τριακόσιες λέξεις / τριακόσια σπίτια
400 τετρακόσιοι τετρακόσιες τετρακόσια τετρακόσια χιλιόμετρα (ср. род)

Порядковые числительные

Порядковые согласуются с существительным по роду и числу: ο πρώτος μαθητής, η πρώτη μέρα, το πρώτο μάθημα.

Ещё примеры: δεύτερος όροφος (второй этаж), τρίτη φορά (третий раз), τέταρτο κεφάλαιο (четвёртая глава).

🧠 Подсказки: будущее и аорист

Ниже рабочая шпаргалка по образованию форм. Для тренажёра главное: видеть тип основы и применять нужную модель.

Будущее: обычно θα + форма будущего (колонка «буд»), например: γράφω → θα γράψω.

Аорист (актив): чаще всего строится через суффикс -σα и его фонетические варианты -ψα / -ξα.

Тип основы Изменение в аористе Модель Пример
Регулярная основа Добавляется σ -σα μιλάω → μίλησα
На π / β / φ σ сливается с согласной -ψα γράφω → έγραψα
На κ / γ / χ σ сливается с согласной -ξα δείχνω → έδειξα
На τ / δ / θ Зубной часто выпадает перед σ -σα πατάω → πάτησα
Глаголы на -ζω Часто смена основы + σ -σα διαβάζω → διάβασα
Глаголы на -σσω / -ττω Переход к кс-сочетанию -ξα πράττω → έπραξα
Часть глаголов на -νω Нерегулярная сильная основа -ηνα / -υνα / и др. μένω → έμεινα, πλένω → έπλυνα
Нерегулярные частотные Форма не выводится по правилу запоминать как пару βλέπω → είδα, λέω → είπα

Дополнительно: в 1-м лице ед. прошедшего часто появляется ε- (augment): γράφω → έγραψα. Отрицание: δεν + аорист.
